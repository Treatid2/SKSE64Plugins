# Publication acceptance boundary

The tester reported the 0.1.57 camera-repair installation retains working Face
View and successful RaceMenu close/reopen via `showracemenu`. Camera-tab options
respond but produce no visible movement; the tester accepts leaving the tab
present. This limitation must remain disclosed, not promoted to a passed test.

Earlier human checks accepted menu stability/reanchoring, picker positioning,
PNG proportions, slider/footer layout, Filter/Name keyboard acceptance, name
save/load, and no repeated naming prompt. SteamVR with VR Menu Mouse Fix was
reported workable, not comprehensively qualified. The original-BSA in-memory
menu route was accepted as indistinguishable from the locally built movie.

On 2026-09-17 the user explicitly requested proceeding with Nexus publishing
and PRs. Release 0.1.58 is a VR beta; it does not imply SE/AE regression, complete
live sculpt/preset coverage, universal controller compatibility or upstream
endorsement. Its only native change from tested 0.1.57 is the version identity.
